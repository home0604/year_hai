Problem

안테나 마스크 역설계

목표 스펙트럼이 주어지면 그것을 만들어내는 10×10 이진 금속 마스크를 생성한다. 기존 접근은 autoregressive (AR) 모델이다. Flow model 로 같은 문제를 풀고 AR 과 비교하는 것이 이 발표의 범위다.

Inputy ∈ ℝ201 목표 S11 스펙트럼 (201 주파수점)
Generateb ∈ {0,1}100 10×10 이진 마스크 — 생성모델이 만든다
Verifyŷ = ffwd(b) 동결된 forward surrogate CNN 으로 재평가

문제의 성격

  • 정방향(마스크 → 스펙트럼)은 함수지만 역방향은 one-to-many — 같은 스펙트럼을 내는 마스크가 여러 개 있다.
  • 따라서 점추정이 아니라 조건부 분포 p(b | y) 의 샘플링이 목표다. 생성모델이 필요한 이유.
  • 데이터: train 167,430 / test 20,929 쌍.

Baseline  AR (snake ordering)

  • 비트를 snake 순서로 하나씩 예측한다: p(b) = ∏k p(bk | b<k, y).
  • chain rule 을 정확히 따르므로 인수분해 오차가 없다.
  • 생성에 100 번의 순차 forward 가 필요하고, 병렬화되지 않는다.

Flow model 은 100 개 픽셀을 매 스텝 병렬로 갱신한다. 관심은 적은 스텝으로 AR 의 품질에 도달하는지다. 아래에서 두 접근을 본다 — CFM 연속 완화, DFM 이산 상태 유지.

Approach 1 · Framework

CFM  기존 vector field 프레임워크를 그대로 가져온다

이진 마스크를 연속값으로 완화한 뒤, 표준 Continuous Flow Matching 을 수정 없이 적용한다.

Sourcex₀ ~ 𝒩(0, I) 표준 가우시안 노이즈
Targetx₁ ~ q(x₁) GT 데이터셋. {0,1} → {−1,+1} 임베딩
Path직선 보간 두 점을 직선으로 잇는다
Learnvelocity vθ 그 직선의 속도를 회귀로 학습

경로와 학습 대상

xt = (1 − t)·x₀  +  t·x₁
ut = x₁ − x₀   (직선의 속도)

모델은 vθ(xt, t, y) 로 이 속도를 예측하고 MSE 회귀로 학습한다. 이진 구조에 대한 별도 처리는 없다 — 이미지 생성에 쓰는 CFM 과 동일하다.

Inference — 적분한 뒤 이산화

  • x₀ ~ 𝒩(0, I) 에서 시작해 Euler 적분으로 t : 0 → 1.
  • 도착한 x₁ 은 연속값이다. 아직 이진 마스크가 아니다.
  • 그래서 마지막에 0 을 기준으로 thresholding 하여 이산화한다: bits = (x > 0)

{−1,+1} 임베딩의 중점이 0 이므로 0 이 자연스러운 결정경계다.

이 CFM 은 이진 대상을 연속 완화로 다루는 접근의 baseline 이다. 핵심 문제는 이산성 우회에 있다: 데이터는 {0,1}100 격자 위에 있는데 연속공간에서 풀고 마지막에 thresholding 으로 되돌린다. 그 과정에서 |x| (per-bit confidence) 는 버려지고, 생성 궤적은 데이터가 없는 연속 영역을 지난다.

참고: 이 구현이 결정론적인 것은 sigma_min = 0 이라 경로에 노이즈가 없기 때문이다 — CFM 자체의 성질이 아니라 설계 선택이다. stochastic path (σ>0) 를 켜면 CFM 도 다양한 샘플을 낸다. one-to-many / 다양성은 이 baseline 이 다루는 축이 아니다.

CFM  Training & Sampling

flow_matching.py — cfm_loss / sample_fm_cfg

Training

# x1: (B, 100) in {0,1} → {−1,+1} 로 임베딩
x1 = xb * 2 - 1

# 1) 노이즈와 시간 샘플
x0 = torch.randn_like(x1)         # 𝒩(0, I)
t  = torch.rand(B)                # t ~ U(0,1)

# 2) 직선 경로 위의 점
x_t = (1 - t) * x0 + t * x1

# 3) 회귀 타겟 = 직선의 속도
u_t = x1 - x0

# 4) MSE 회귀
v    = model(x_t, t, y)             # out: ℝ^100
loss = ((v - u_t) ** 2).mean()

Sampling

# Euler ODE 적분, t: 0 → 1
x  = torch.randn(B, 100)         # x0 ~ 𝒩(0, I)
dt = 1.0 / N

for i in range(N):
    t = i * dt
    v = model(x, t, y)              # velocity
    x = x + v * dt                  # clamp 없음

# 연속값 → 이진 마스크
bits = (x > 0).long()              # thresholding

NFE = N (병렬). 100 개 픽셀이 매 스텝 한 번에 갱신된다 — AR 의 100 회 순차와 대비되는 지점이다.

Approach 2 · Framework

DFM  이산 상태를 유지한 채, 확률분포의 velocity field 를 학습한다

연속으로 완화하지 않는다. 각 픽셀의 vocab 을 {0, 1} 로 정의하고, 모델이 상태의 확률분포를 직접 예측하게 한다.

VocabV = {0, 1} 픽셀당 2 개 심볼. 상태는 끝까지 이산
Sourcep₀ = Uniform 균등분포에서 출발 (가우시안 아님)
Targetp₁ = q(x₁) GT 데이터셋
Learn확률의 velocity 분포를 p₀ → p₁ 로 나르는 rate

모델이 예측하는 것 (V=2) — 픽셀마다 확률을 내고, 거기서 {0,1} 을 뽑는다

이 픽셀별 확률 p1|t(x₁ | xt) 이 아래 rate 를 결정한다. (V=16 으로 묶는 방법은 6 장)

1 · 조건부 경로  (x₁ 을 하나 고정했을 때)

pt(x | x₁) = t·δ(x, x₁) + (1 − t)·(1/V)

각 픽셀을 확률 t 로 정답값에 유지하고, 나머지 (1−t) 확률로 uniform 하게 새로 뽑는다. t=0 이면 완전 균등, t=1 이면 완전 정답.

2 · Marginalization  (데이터셋 전체에 대해)

pt(x) = 𝔼x₁ ~ q [ pt(x | x₁) ]

GT 데이터셋을 target 으로 주변화하면, 균등분포에서 데이터분포로 이어지는 확률경로 pt 가 정의된다.

3 · 이 확률경로를 나르는 velocity field (rate matrix)

ut(v, z) = λt · [  p1|t(v | z)  −  δ(v, z)  ] ,     λt = 1 / (1 − t)

연속 CFM 의 velocity 에 대응하는 이산판이다. 이 rate 는 p1|t(x₁ | xt) 하나로 결정된다 — 모델은 rate 를 직접 예측하지 않고 깨끗한 데이터의 사후확률만 예측하며, rate 는 거기서 복원된다.

연속 FM 의  v = (x̂₁ − xt) / (1 − t)  와 정확히 같은 구조다.  ·  문헌 용어: probability denoiser (x-prediction), Gat et al., NeurIPS 2024.

DFM  Training & Sampling

flow_matching.py — dfm_loss / sample_dfm_cfg

Training

# x1: (B, 100) in {0,1} — 이산 그대로
t = torch.rand(B)                  # t ~ U(0,1)

# 1) 조건부 경로에서 x_t 를 샘플
#    확률 t 로 유지, 아니면 uniform 재추출
keep = torch.rand(B, D) < t[:, None]
rnd  = torch.randint(0, 2, (B, D)).float()
x_t  = torch.where(keep, x1, rnd)

# 2) 모델은 깨끗한 x1 의 사후확률을 예측
logits = model(x_t * 2 - 1, t, y)  # ℝ^100

# 3) BCE — 타겟은 원본 x1
loss = F.binary_cross_entropy_with_logits(
           logits, x1)

*2−1 은 {0,1}→{−1,+1} 입력정규화다. 전단사 아핀변환이라 첫 레이어가 흡수한다.

Sampling  CTMC 유한전이

# uniform 에서 출발
x = torch.randint(0, 2, (B, D)).float()

for i in range(N):
    t  = i / N
    p1 = sigmoid(model(x*2-1, t, y)) # P(x1=1)

    # 사후확률에서 후보를 뽑고
    r = (p1 > .5) if last else (rand < p1)

    # 확률 a 로만 점프, 나머지는 x_t 유지
    a = 1 / (N - i)               # = (t'−t)/(1−t)
    x = torch.where(rand < a, r, x)

return x.long()                    # 이미 이진 — 후처리 불필요

a ∈ (0,1] 이 자동 보장된다. λt 는 t→1 에서 발산하지만 구간을 닫힌형태로 적분해 흡수하므로 clamp 가 필요 없다.

CFM xt ∈ ℝ100 (연속) v ∈ ℝ100 — velocity MSE thresholding 필요
DFM xt ∈ {0,1}100 (이산) logits → sigmoid = p1|t(x₁ | xt, y) BCE 이미 이진

Patchify · 그림으로

Patchify 를 그림으로

먼저 그림으로 개념을 본다. 위: 픽셀을 묶어 토큰을 만드는 방법. 아래: 그로 인해 달라지는 점. 다음 장에서 코드와 함께 다시 정리한다.

2×2 픽셀을 토큰 1 개로 묶는다

2×2 흑백 배치는 2⁴ = 16 가지 → 각 배치를 토큰 하나로 (vocab 16)

g=1 · 픽셀마다 확률  (4 장에서 본 방식)

픽셀마다 확률을 정하고, 각 픽셀을 금속/빈칸으로 따로 뽑는다

g=4 · 배치마다 확률

16 가지 배치 전체에 확률을 정하고, 그중 하나를 통째로 뽑는다

두 방법 모두 같은 배치가 나올 수 있다. 차이는 확률을 어디에 두는가다 — g=1 은 픽셀을 따로 뽑으므로 "왼쪽 위가 금속이면 아래도 금속" 같은 픽셀 사이의 관계를 표현하지 못하고, g=4 는 16 가지 배치에 직접 확률을 주므로 그 관계를 담을 수 있다.

collision — 노이즈가 원래 값과 우연히 같을 확률

묶을수록 이 확률이 낮아진다 → 노이즈를 줬을 때 실제로 더 많이 바뀐다

노이징 단위 — 비트마다 vs 패치 통째로

유지/교체가 비트 단위인가 패치 단위인가

금속 (1)  ·  빈 곳 (0)  ·  노이즈로 교체됨

Approach 2+ · Vocab merging

Patchify  픽셀을 묶어 vocab 을 키운다

DFM 을 V=2 로 그대로 쓰면 학습이 잘 되지 않는다. 원인은 collision 이다.

문제 — collision

"uniform 하게 새로 뽑는다"고 했지만, 새로 뽑은 심볼이 우연히 원래 값과 같을 확률이 1/V 다. 따라서 실제 flip 확률은 (1 − t) · (V−1)/V 이다.

V=2 는 t=0 (완전 노이즈) 에서도 절반만 뒤집힌다. 노이즈가 섞인 입력과 원본을 구분할 신호가 약해 gradient 가 잘 서지 않는다.

해법 — 2×2 공간 패치를 1 토큰으로 (g=4, V=16)

# raster 로 묶으면 1×4 가로줄이 된다 →
# 2×2 공간 패치 순서로 재배열 후 묶는다
fwd, inv = make_spatial_patch_indices(H, W, 2, 2)
X = X[:, fwd]

# 4 bits → 1 token ∈ {0..15}
tok = bits_to_tokens(x1, group_size=4)

# 노이징: 토큰 단위 uniform 재추출
keep  = torch.rand(B, T) < t[:, None]
tok_t = torch.where(keep, tok,
          torch.randint(0, 16, (B, T)))

# Loss: BCE → Cross-entropy 로 바뀐다
loss = F.cross_entropy(
    model(tok_t, t, y).reshape(-1, 16),
    tok.reshape(-1))

# Sampling 은 동일. multinomial 로 토큰을 뽑고
# 같은 a = 1/(N−i) 로 점프 여부만 결정한다.

Patchify 로 달라지는 점

1 · 출력 형태

g=1 은 비트별 베르누이 100 개를 독립으로 출력한다. g=4 는 토큰당 16-way categorical 을 출력하므로, 묶인 4 비트의 결합분포를 표현한다.

2 · collision  (측정됨)

uniform 재추출이 원래 값과 같을 확률이 1/2 → 1/16 로 낮아진다. t=0 의 실제 flip 확률이 0.500 → 0.938 이 된다. 07-05 에서 관찰한 V=2 학습 부진과 직접 연결된다.

3 · 노이징이 적용되는 단위

g=1 은 비트마다 독립으로 유지/교체하므로 2×2 패치가 통째로 유지될 확률이 t⁴, g=4 는 토큰 단위라 t 이다 (t=0.5 에서 0.0625 vs 0.5). 유지/교체가 개별 비트가 아니라 패치 단위로 일어난다.

전자기적으로 인접한 셀을 한 토큰에 넣기 위해 raster 대신 2×2 공간 패치로 재배열한다.

1 · DFM V=16 이 AR 을 앞선다

notch MSE 36.53 vs 39.60 — DFM 이 낮다. 그리고 AR 은 100 회 순차인 반면 DFM 은 10 회 병렬이다. guidance 없이 얻은 결과다.

2 · V=2 와 V=16 의 차이

같은 조건에서 V=2 는 44.98, V=16 은 36.53 이다. V=2 는 AR (39.60) 도 넘지 못한다. collision 의 영향이 성능 차이로 나타난다.

3 · CFM (이산성 우회 baseline)

CFM 은 주 지표에서 가장 높다 (60.64). 이진 대상을 연속으로 풀고 thresholding 으로 되돌리는 데서 오는 손해다 — DFM 은 상태를 이산으로 유지하고, 그 차이가 주 지표에 나타난다.

지표 참고. notch MSE 는 타겟이 −10 dB 이하인 공진 구간에서만 잰 MSE 다 (test 타겟의 74% 는 공진이 없어 전체 스펙트럼 평균은 신호가 희석된다). 지표 정의·코드는 논문을 그대로 따랐으나, 측정 대상(우리 test set)과 후보 예산(best-of-10)이 논문과 달라 논문의 절대값(dual-band, 35,500 후보)과 직접 비교하는 수치가 아니다. 목적은 AR vs FM 의 상대 비교다.

valid@10 (10 개 중 하나라도 모든 notch 를 −12 dB 아래로 만드는 비율) 은 AR 이 약간 높다 (0.633 vs 0.591) — 후보 다양성은 AR 이 넓지만, best 후보의 품질(notch MSE)은 DFM 이 앞선다. BitAcc·PatAcc 는 GT 마스크와의 일치율이라 one-to-many 에서 유효한 대안 해를 벌주는 sanity 지표다. AR 은 teacher forcing 이 아니라 실제 100 스텝 생성으로 평가했다.
